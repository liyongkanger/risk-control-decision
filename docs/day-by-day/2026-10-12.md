# Day 1｜2026-10-12：打通场景与可视化流程

## 开发计划

- 在已有 Java 服务骨架、LiteFlow 示例链和 X6 示例画布的基础上，确定场景、流程版本、组件与节点的关系。
- 让画布中的结构化流程能够保存、校验、发布，并通过场景入口同步执行。

## 实际开发

- 定义独立于 X6 序列化格式的流程图契约，支持串行、条件分支、并行分支及对应汇合的结构校验。
- 将图转换成 LiteFlow EL，并接通节点实例、场景流程持久化、版本发布和按场景执行。
- 接通 X6 画布与后端流程接口，补上发布一致性校验。
- 梳理 Java 分层、组件分包、数据库字段和表结构等项目约定。

## 问题与解决

- **画布能画出的图不一定能安全执行。** 保存草稿与允许发布分开；发布前由后端校验图结构和组件配置。
- **发布过程中可能出现运行版本不一致。** 固定不可变发布版本，并在发布切换时校验草稿修订号和原发布指针；执行请求使用开始时选中的版本。
- **项目从零开始，代码风格容易分散。** 将讨论结果沉淀到项目开发和分层规范，作为后续实现依据。
