# 子流程画布接入设计

日期：2026-10-14
状态：已确认并实施；页面验收以代码、测试及本地 H2 联调记录为准。

## 目标

在现有 X6 编辑器中完成子流程引用的选择、输入映射、结果配置和试运行结果查看。沿用已实现的 `SUBFLOW`、`RESULT`、`requiredInputs` 与 `ApiResponse<T>` 契约，不在前端复制后端校验规则。

## 后端交接补充

新增只读 `GET /api/flows/{flowCode}/published`，返回当前发布版本的 `id`、`flowCode`、`versionNumber`、`requiredInputs`。无当前发布版本时返回 404 `NOT_FOUND`。列表继续按 `GET /api/flows?keyword=&page=&pageSize=` 搜索；画布选中流程后再读取摘要，固定其 `id` 作为 `SUBFLOW.config.versionId`。已有草稿若固定 ID 与当前 ID 不同，显示“版本已更新”，只在用户明确操作后升级。

## 画布操作

- 节点栏增加 `SUBFLOW` 与 `RESULT`。新 `SUBFLOW` 节点初始配置为空，可保存不完整草稿；完成选择后才可通过校验和发布。
- 画布提供“本流程必需输入字段”编辑框，按逗号或换行录入，写入图顶层 `requiredInputs`；原有草稿读取后保持字段，重载模板时按模板内容替换。
- 子流程节点检查器提供流程搜索、分页、当前已发布版本信息；选择流程后列出其必需输入，每项选择“请求输入”或“上游节点结果”，再输入来源字段/节点 ID 与路径。保存映射写入 `inputMappings`，保持固定版本 ID。
- `RESULT` 节点检查器分别编辑 `conclusion`、`reasonCode`、`reason`、业务明细 JSON、可选建议动作。`equals-value` 条件节点提供来源节点、路径及预期值字段；旧 `is-positive` 继续提供输入字段。
- 所有配置变更清除当前校验状态；仍须先保存同一图快照、再校验、最后发布。后端返回的 `GraphIssue.nodeId` 继续定位画布节点。
- 场景画布试运行输入使用 JSON 对象编辑，默认 `{ "positive": true }`。结果区分运行状态、外层业务结论、各子流程调用的结论与版本；运行失败展示错误码、失败调用节点及可用的子流程轨迹。旧发布版本 `businessResult=null` 显示“未定义业务结果”。

## 边界

当前版本选择只显示子流程当前发布版本；历史版本不能在新草稿中重新选择。列表搜索为后端分页，不把全部资产加载到前端。页面不模拟子流程结果；试运行调用真实场景接口。独立流程的直接试运行接口尚未提供，独立流程画布仍通过场景绑定后试运行。

## 验收

1. 用户能从流程资产列表选中已发布子流程，看到固定版本及其必需输入，配置来源后保存、校验、发布外层流程。
2. 加载旧草稿时保留其版本与映射；子流程发布新版本后页面只提示，显式升级才修改草稿。
3. 能配置真、假两条结果路径；试运行展示外层结果与两个子流程各自的结果和版本，失败不会显示正常结论。
4. 前端测试、类型检查、构建和真实浏览器联调通过；接口文档与后端响应一致。
