# 规则变量统一来源设计

状态：已按本文实现并通过本地联调。

## 目标与边界

规则的每个业务输入必须引用变量中心的不可变变量版本。规则保存条件、阈值、命中结果，不保存取值参数映射。尚未进入生产测试，旧的未绑定规则输入契约直接重构，不做历史运行兼容。营销样板及本地演示数据按新契约重新初始化；实施不得自动删除用户的本地数据库或覆盖未发布草稿。

## 变量来源

- `REQUEST_INPUT`：变量码等于当前流程输入字段名，值来自本次流程请求。规则独立试算由操作者提供该字段。
- `FLOW_CONTEXT`：变量中心保存全局可复用的名称和类型；每条流程把该变量的固定版本绑定到唯一生产节点和结果字段路径。值只在本次、当前流程中存在。子流程通过输入映射显式传递。
- `HTTP_GET`、`DEMO_MARKETING`：保留已有外部来源。其 `parameterNames` 必须指向变量中心的其他变量；运行时递归解析依赖，拒绝循环依赖和缺值。

所有变量引用固定版本 ID。更新变量后需要重新发布受影响的规则与流程；已发布版本的配置不变。规则中心不再接受直接输入或任意执行上下文字段映射。外部变量参数与被引用变量同名；发布流程时递归检查这些依赖所需的请求字段和上下文生产节点。

## 流程绑定与运行

流程图携带上下文变量绑定列表，元素包含 `variableCode`、`variableVersionId`、`nodeId`、`resultPath`；空 `resultPath` 表示整个标量节点结果，非空点分路径读取对象字段。同一流程内同一变量码只能出现一次；生产节点必须存在，并位于消费规则节点上游。发布时检查变量版本、类型及已知组件的输出字段；开始、结束、汇合、条件和结果节点不能作为生产者。动态业务明细在运行时检查实际路径和值类型。若该路径没有经过生产节点、结果字段不存在或类型不符，本次决策失败，错误指明变量。不同流程可为同一变量指定不同生产节点。

规则节点仅固定规则版本；取值器在当前流程的请求输入、节点结果和流程绑定中解析规则变量及其依赖。同一次规则求值的全部输入共享变量解析缓存，相同固定版本的外部变量只取一次。单独试算时，请求输入由操作者填写，流程上下文变量使用明确标记的临时样例值，外部来源真实取值。试算样例不写入变量中心，也不影响正式决策。

## 页面与交接

变量中心表单按来源显示相应字段。规则中心每个输入必须选变量，类型由变量版本确定；移除直接输入、参数映射和规则节点输入映射编辑。流程画布提供上下文变量到生产节点及结果路径的配置。`docs/api/variable-center.md`、`docs/api/rule-center.md`、`docs/api/flow-assets.md` 与实现同步更新。验收覆盖保存与发布校验、请求/上下文/外部取值、依赖环、缺失值、子流程隔离、规则试算和营销样板完整链路。
