# 产品定位

状态：方向已确认，具体业务样板与效果指标待确定。

## 我们要做的产品

建设一个可用于风控、营销等业务的通用决策平台。业务人员能够定义决策目标、配置策略、测试模拟、发布版本、观察结果并据此调整策略，形成完整的产品闭环。

平台中的业务能力以节点接入，决策流程负责组合这些能力并给出可解释的业务结果。不同业务可以定义自己的结论和明细；平台提供一致的设计、发布与追溯体验。

## 服务的用户

| 用户 | 主要任务 |
| --- | --- |
| 策略设计者 | 配置和复用决策能力，验证策略修改的结果。 |
| 业务负责人 | 明确决策目标和可接受的业务结果，判断策略是否有效。 |
| 测试与运营人员 | 测试发布前的行为，追溯发布后的具体决策与后续效果。 |

## 产品边界与演进

- 首轮优先让决策流程返回明确的业务结论、原因和可选建议动作；运行成功与业务结论分开表达。
- 决策流程可以独立发布并被外层流程作为子流程调用。外层调用多个子流程时，最终业务结果由外层显式决定。
- 后续保留执行流程及业务动作节点的产品方向。执行流程可调用决策流程，再推动业务步骤；建议动作与实际执行结果应分开呈现。
- 风控、营销用于验证产品的通用性，首批真实样板场景及衡量指标尚未确定。
